# Severity Rubric

Use this rubric to keep reports consistent.

## High

The issue creates a likely bug, a high-maintenance hotspot, or a strong risk of divergent behavior if left as-is.

## Medium

The issue creates avoidable complexity or maintenance risk, but the code is still serviceable in the short term.

## Low

The issue is a legitimate improvement opportunity, but the current code is unlikely to create immediate harm.

## Confidence rubric

- `High`: direct evidence in the reviewed files clearly supports the finding
- `Medium`: evidence is strong but some project context could change the recommendation
- `Low`: the concern is plausible but depends on assumptions that should be verified
